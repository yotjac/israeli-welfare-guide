# המדריך הפיננסי לאזרח בישראל

A single-page Hebrew guide to managing Israeli welfare accounts (pension, keren hishtalmut, gemel, insurance, Bituach Leumi), written the way a pension advisor (יועץ פנסיוני) would walk you through it.

## What's inside

- **הבדיקה השנתית**: an 8-step annual review, with a management-fee checker
- **התיק שלי**: a form to record each of your funds and policies and their status
- **סיכום התיק**: an automatic summary with totals, savings breakdown, alerts and open tasks
- Explainer pages: pension, hishtalmut & gemel, health, life & disability, Bituach Leumi & tax, official tools, yearly checklist

## Running it

It's one static file with no build step. Open `index.html` in a browser, or host it with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).

## Privacy

Anything you enter in **התיק שלי** is stored only in your own browser's `localStorage`. It is never sent anywhere
and is not part of this repository. Backup files you export (`welfare-backup-*.json`) are git-ignored, so they
won't be committed by accident.

## Disclaimer

General information only, not pension, financial or legal advice. Ceilings, tax rates and fee benchmarks change every year.
